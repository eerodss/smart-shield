# Smart Shield — Site Institucional

Site institucional desenvolvido para a **Smart Shield**, com foco em apresentação da empresa, catálogo de produtos e captação de parceiros.

## 🚀 Funcionalidades

- Página inicial institucional
- Catálogo de produtos
- Filtros por categoria
- Busca de produtos
- Páginas individuais dos produtos
- Sistema de breadcrumb
- Página para parceiros
- Formulário de interesse comercial
- Layout responsivo
- Animações e interações com JavaScript
- Publicação via GitHub Pages

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages

## 📁 Estrutura

```text
main/
├── index.html
├── catalogo.html
├── individual.html
├── parceiros.html
├── js/
├── imagens/
     └── produtos/
```
